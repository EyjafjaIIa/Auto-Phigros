Phigros 自动打歌 —— 双击即用的两个入口
================================================

1-导入谱面.bat
    检查环境 → 连接手机 → 从手机里拉取 Phigros 安装包 → 解出 assets →
    解码全部谱面并保存到 charts\。

2-自动打歌.bat
    用 adb 截屏当前画面 → OCR 识别选中的曲目、按标签颜色判断难度 →
    找到对应谱面 → 启动自动打歌。

使用前提
------------------------------------------------
* Windows 10/11，已安装 Python 3.10+（安装时勾选 Add to PATH）
* 手机开启 USB 调试，并用数据线连着电脑
* 仓库目录里要有 scrcpy（带 adb.exe），或 adb 已在 PATH 中
* 游戏停在选歌界面，选中你想打的那首歌和难度

打歌时的操作
------------------------------------------------
* 进歌后，在**第一个音符压到判定线**的一瞬间按回车或空格
* 偏早/偏晚用 ↑/↓（20ms）、PageUp/PageDown（200ms）现场调
* 结束会把偏移记进 calibration.json，下次作为起点

一局打完后会出现菜单：

    1 = 记住这次偏移，再打一遍
    2 = 退出

选 1 之后，先手动回到选歌界面（选中同一首或下一首），再按回车，
程序会重新截屏识别并开打；输入 q 回车则退出。

常见问题
------------------------------------------------
* 「没找到 Python」：重装 Python 并勾选 Add python.exe to PATH
* 「没找到 adb」：把 scrcpy 解压到仓库目录，或装 platform-tools
* 「没检测到手机」：换一根能传数据的线，确认手机弹窗点了允许
* 「识别失败」：把手机停在选歌界面（曲目名清晰可见）再双击一次
* 识别出的曲目不对：确认选歌界面没有开随机/筛选，再试一次
